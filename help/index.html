Help: using the calculator, step by step

If you are stuck, start here. The calculator has three main modes: plant values, pet maths, and trade lists. You do not need an account for any of them, and your calculations stay on your device unless you choose to share them, for example by screenshot.

Quick start

  1. Open the calculator and choose a plant or pet.
  2. Enter the exact weight, tier, and other numbers shown in the game.
  3. Add mutations from the search list. Use the search to find a mutation by name or keyword.
  4. Check the total, then save it as a line item if you are building a list.
  5. To estimate weight from a target value, enable Value to weight mode and enter the target value instead.

Common issues

  • List total changed: each saved line stores the value at the moment you added it. Changing settings later does not rewrite old lines.
  • Modifier says reference only: that entry is shown for awareness and may not be mapped to the active formula.
  • Value looks different in game: values are estimates from bundled data. Game updates can change them, so compare with in-game values for large trades.
