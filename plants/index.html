Plants, values, and categories in one place

The Plants page is the starting point for most calculations. You can browse plants by category, sort by value from high to low, and open a plant to calculate its value with weight, tier, and mutations. Categories include Seed Shop, Exotic Seed Pack, Limited Rewards, and event categories such as Easter, Night, Bee, and Summer, so you can find event plants without scrolling through everything else.

How to use the Plants page

  1. Choose a category that matches the plant you have.
  2. Sort by value if you are comparing plants for a trade.
  3. Enter the exact weight and tier shown in the game.
  4. Add mutations one by one and watch the total change.
  5. Save the result as a line item if you are building a trade list.

What affects a plant's value

  • Base value: the starting value for that plant.
  • Weight: heavier fruit usually means a higher value, but the effect is not always linear.
  • Fruit tier: tier changes the calculation, so do not skip it.
  • Mutations: each mutation applies its own multiplier, and stacks can change the result dramatically.
  • Amount and friend boost: moving more than one plant, or playing with a friend boost, changes the line total.

Because of those five factors, two plants with the same name can have very different values. That is why the calculator asks for all of them instead of giving you a single fixed price. Use the main calculator for the full calculation, and Guides if you want a worked example.
