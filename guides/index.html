Guides for practical, everyday play

Guides are short, practical workflows, not theory. They cover the three questions players ask most: how to calculate a value correctly, how to stack mutations safely, and how to plan a trade without overpaying. Each guide follows the same order used by the calculator, so you can read a guide and then do the same steps in the tool.

Recommended reading order

  1. Beginner crop value workflow: choose a plant, enter weight and tier, add mutations, check the total.
  2. How to stack modifiers safely: add one mutation at a time, check reference-only labels, and do not assume every label changes the formula.
  3. Weight versus value planning: decide whether you need more weight, a better tier, or a different mutation stack.
  4. Friend boost and amount scaling: check how amount and boosts change a line total before you commit to a trade.

A simple rule for every guide

Change one thing at a time. If you change weight, tier, and mutations together, you will not know which change moved the total. The calculator is most useful when you test one change, note the result, and then test the next one. The Blog has longer worked examples, and FAQ answers the most common calculation questions.
