Weather events — mutation sources

Weather in Grow a Garden is timed and changes in-game, so this page is a reference for which weather gives which mutation — not a live tracker. Check the game for the current weather, then use the calculator to value a crop with that mutation.

  • Rain / Gentle Drizzle: Rain increases growth and can apply Wet. Gentle Drizzle is a softer rain route. Mutations: Moist ×3
  • Snow / Frost: Snow weather can apply Chilled, and cold routes build to Frozen. Snowfall covers seasonal snow mutations. Mutations: Chilled ×2, Snowy ×2, Snowtouched ×5
  • Thunderstorm: Thunderstorms can strike crops with Shocked, one of the highest weather multipliers in the calculator. Mutations: Shocked ×100
  • Night / Blood Moon: Night applies Moonlit. Blood Moon can replace Night and applies Bloodlit. Mutations: Moonlit ×2, Bloodlit ×4
  • Sandstorm: Sandstorm applies Sandy, which can combine with wet-style mutations toward Clay-style fusions. Mutations: Sandy ×3
  • Heat Wave: Heat Wave applies Sundried, a high multiplier that can combine with Verdant toward Paradisal. Mutations: Sundried ×85
  • Aurora Borealis: Aurora Borealis applies Aurora and supports higher combinations such as Cosmic with Celestial. Mutations: Aurora ×90
  • Tropical Rain: Tropical Rain applies Drenched, a flooded-weather route separate from standard Rain. Mutations: Drenched ×5
  • Acid Rain: Acid Rain applies Acidic and helps with Corrosive-style fusion sources. Mutations: Acidic ×15
  • Eclipse: Eclipse weather applies Eclipsed. Mutations: Eclipsed ×20
  • Safari Weather: Safari-era weather includes Nocturnal and Twilight notes. Mutations: Nocturnal ×4, Twilight ×4
  • Smithing Fever: Smithing Fever weather is tracked for Tempered and related crafting entries. Mutations: Tempered ×6
  • Rainbow Event: Rainbow Event weather is noted for Luck in the calculator data. Mutations: Luck ×3
  • Admin / Event Rain: Admin and event rain routes in the data include Fried Rain, Oil Rain, Boil Rain and Midas Rain. These are admin-event mutations, not standard weather. Mutations: Fried ×8, Oil ×15, Boil ×15, Gilded ×15

Sources are the mutation descriptions in the calculator data. If a weather route changes in a patch, send a correction and we will verify it before updating. Fan-made, not affiliated with Roblox or Grow a Garden.
